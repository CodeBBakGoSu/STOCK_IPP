# 뉴스 분석 도구

이 도구는 CSV 형식의 뉴스 데이터셋에 대해 다양한 NLP(자연어 처리) 분석을 수행합니다.

## 기능

1. **TextRank 기반 텍스트 요약**: 뉴스 본문의 중요 문장을 추출하여 요약합니다.
2. **KeyBERT 기반 키워드 추출**: 뉴스 본문에서 핵심 키워드를 추출합니다.
3. **finBERT 기반 감성 분석**: 뉴스 본문의 감성(긍정/부정/중립)을 분석합니다.
4. **TF-IDF 기반 유사 뉴스 검색**: 유사한 내용의 뉴스를 찾아 제시합니다.

## 설치 방법

1. 필요한 라이브러리 설치:
```bash
pip install -r requirements.txt
```

2. NLTK 추가 데이터 다운로드:
```python
import nltk
nltk.download('punkt')
```

## 사용 방법

1. 뉴스 데이터 CSV 파일을 준비합니다 (예: `stock_news_20250513_032406.csv`).
2. `news_analyzer.py` 스크립트를 실행합니다:
```bash
python news_analyzer.py
```
3. 메뉴에서 원하는 분석 옵션을 선택합니다.

## 데이터 형식

분석할 CSV 파일은 다음 열을 포함해야 합니다:
- `title`: 뉴스 제목
- `content` 또는 `description`: 뉴스 본문

## 분석 결과 예시

### TextRank 요약
원본 텍스트에서 가장 중요한 문장들을 추출하여 요약을 생성합니다.

### KeyBERT 키워드 추출
텍스트에서 가장 의미 있는 키워드와 그 관련성 점수를 제공합니다.

### finBERT 감성 분석
텍스트의 긍정/부정/중립 점수를 계산하여 전반적인 감성을 분석합니다.

### TF-IDF 유사 뉴스 검색
TF-IDF 벡터화와 코사인 유사도를 사용하여 유사한 내용의 뉴스를 찾습니다.
